# Repository input

Record the revision and any included local changes. Inspect architectural centers of gravity and representative normal and failure or recovery flows. Record sampled paths and coverage limits; a sample is not exhaustive coverage.

Inspect manifests, entry points, domain models, state ownership, background work, concurrency, authorization, configuration, telemetry, tests, CI, deployment, and operations where relevant. Skip generated and vendored code, lock files, and build artifacts unless they support a specific claim.

Stop when each central boundary has representative normal and failure coverage, or missing evidence is recorded. Use Architectural status for repository risks in a formal review.
